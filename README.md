# Thiva Engineering - React Frontend (SPA)

A dynamic Single Page Application (SPA) built using **React** and **TypeScript**. This project serves as a demonstration of high-level proficiency in React-specific patterns, state management, and client-side integration with a headless Laravel backend.

---

## Key Features & Implementation

### Pure React Architecture
* **Client-Side Rendering (CSR):** Developed using a standard React lifecycle to provide a fluid, app-like user experience with instant transitions.
* **Type-Safe Development:** Leveraged **TypeScript** interfaces and types to ensure strict data integrity when communicating with the external API.
* **Dynamic Routing:** Implemented client-side routing to manage complex page hierarchies while maintaining state across the application.

### UI & Styling
* **Tailwind CSS:** Utilized a utility-first approach to build a fully responsive, modern UI with optimized CSS delivery.
* **Reusable Components:** Designed a modular component library, allowing for rapid scaling and consistent UI/UX patterns.

### Quality & Testing
* **Unit Testing:** Integrated **Jest** and **React Testing Library** to perform automated testing on core business logic and UI components, ensuring a bug-free user flow.

---

* **Library:** [React](https://reactjs.org/)
